# Material state examples

Open these in **Panels > Material State** (`concepts.material-state`). The values are
illustrative.

| Project | What it shows |
|---|---|
| `a-evolving-conductor.resonant` | a saline gel heated by a 2.45 GHz wave for 10 minutes: its conductivity falls with the temperature, step by step |
| `b-thermomechanical-expansion.resonant` | a constrained polymer plate heated inside: it thickens and builds compressive stress |
| `c-plastic-bar.resonant` | steel cycles with isotropic and kinematic hardening, and a bar fixed at both ends that keeps residual stress |
| `d-damage-resonance.resonant` | a laminate cantilever cycled to growing deflections: root damage lowers its frequencies (also a functional structure) |
| `e-phase-change.resonant` | a paraffin wall melting from a warm face, against the Stefan solution |
| `f-hysteretic-core.resonant` | a ferrite toroid: a major and a minor Preisach loop, loss per cycle and power at 50 Hz |

Every example is run by `MaterialStateExamples.*`.
