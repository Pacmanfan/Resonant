# Demonstration assets

Demonstrations use the versioned example projects in `examples/` and the data
files bundled with them. Data that is not a real measurement says so in its
own header and in the profile's `data` list; demonstration G uses
`examples/experiments/rlc_antenna_and_line.s2p`, which is SYNTHETIC.

Put a new asset here only when no example holds it, label its origin
(measured, with instrument and date; or synthetic, with how it was made), and
list it in the profile. Do not store simulation caches or run output here.
