# Demonstration screenshots

A demonstration's `capture` steps write into its run folder (in the user's data
folder: `~/.local/share/Resonant/demo-runs/<profile>-<time>/`), with the run
manifest. Copy curated captures here only when they are used outside the help;
the help's screenshots are captured by `resonant --capture-screenshots
help/screenshots/manifest.json` into `help/src/images/screenshots/`.
