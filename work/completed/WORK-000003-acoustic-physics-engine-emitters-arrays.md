## Scope

Acoustic physics engine: emitters, arrays, analytical propagation, focusing, inverse design, field simulation and visualization

## Implementation

- `src/core/acoustics` — conventions, medium (ideal-gas air, nominal water), components (emitter, array with per-element overrides, target, probe, region), propagation interface and free-field model, field evaluator (pressure, velocity, active intensity), focusing (phase / time delay, tapers), inverse design (SVD, relative Tikhonov), grids, preflight estimate, threaded field job, snapshot results, point reports with CSV / JSON export, project-level settings.
- `src/core/simulation/SimulationResult.h`, `SetProjectExtensionCommand` — result base class; undoable project-level settings.
- `src/render/FieldLayer` — complex field on a plane or as volume slices from a texture; quantity, scale and animation phase as uniforms.
- `src/app` — `AcousticController`, `AcousticsPanel`, `FieldAnalysisPanel`, `AcousticEditors` (emitter, array, target, region), `AcousticMarkers`; six new Qt Designer forms; Acoustics menu, toolbar and dock in `MainWindow.ui`; decorators in `SceneRenderBridge`; `--run-field` option.
- `examples/acoustics` — four example projects generated by the engine.
- `docs/acoustics` (six documents), `docs/requirements/acoustics.md`, ADR-000207, status, decision index, architecture overview, manifests.

## Tests

- New: `tests/core/test_acoustics.cpp` (45 cases of numerical validation against closed-form expectations), `tests/core/test_acoustic_examples.cpp` (4 cases; each example file is compared with what the engine builds and its physics is checked), `tests/app/test_acoustics_ui.cpp` (13 cases through the real main window).
- The linked run: tier t2, PASS: core 115 cases, app 49 cases, cmake build + CTest, layering.
- By hand, not part of the gate: the application started on a virtual display with `--run-field --screenshot` for examples A, C and D; the image of example C shows the array, the field plane and the focused beam at the target, with the target value 607.2 Pa in the analysis panel. Release-build timing recorded in `docs/acoustics/ACOUSTIC_VALIDATION.md`.
