## Common workflows

- Focus an ultrasonic array on a point: [Focusing](acoustics/focusing.md).
- Find the resonances of a plate: [Modal analysis](mechanics/modal.md).
- Steer an antenna array and lower its sidelobes: [Beamforming](electromagnetics/beamforming.md).
- Let Resonant search for a better design: [The Optimization Studio](optimization/studio.md).
- Compare a measurement with a simulation: [Simulation correlation](experiments/correlation.md).
- Script and automate a study: [The Python console](python/console.md), [Workflow automation](python/workflows.md).
- Present a capability: [Demo Studio and presenter mode](ui/demo-studio.md).
